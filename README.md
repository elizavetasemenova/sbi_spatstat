# Amortized Simulation-Based Inference for Log-Gaussian Cox Processes

Calibrated, likelihood-free Bayesian inference for the parameters of a
grid-discretized **Log-Gaussian Cox Process (LGCP)** using amortized **Neural
Posterior Estimation (NPE)** — a convolutional summary network feeding a masked
autoregressive flow.

After a one-time training cost, the method returns a full posterior over the
three interpretable LGCP parameters — baseline log-intensity `β₀`, spatial
variance `σ`, and correlation range `ℓ` — for any new count grid in
milliseconds, and is validated to match gold-standard NUTS at a
~10³–10⁴× lower per-dataset cost.

The paper (`paper/paper.pdf`) is generated end-to-end from these experiments.

## Headline results

- **Calibrated.** The NPE posterior passes simulation-based calibration (SBC) on
  all three parameters and attains near-nominal credible-interval coverage. A
  point-estimate CNN regressor, by contrast, is severely overconfident.
- **Faithful.** NPE posteriors are statistically indistinguishable from NUTS
  (classifier two-sample accuracy ≈ 0.5) dataset by dataset.
- **Fast.** Milliseconds per dataset vs. seconds–minutes for MCMC; the training
  cost is repaid after a handful of datasets.
- **Honest.** A kernel-misspecification study shows graceful, diagnosable
  degradation rather than silent failure.

## Repository layout

```
sbilgcp/                 core library
  lgcp.py                LGCP prior, batched simulator, parameter transforms,
                         hand-crafted spatial summaries
  flows.py               conditional Masked Autoregressive Flow (from scratch)
  npe.py                 CNN/MLP embeddings, NPE model + trainer, regressor baseline
  reference_mcmc.py      gold-standard NUTS (NumPyro), non-centred latent field
  diagnostics.py         SBC, coverage, recovery, C2ST, Wasserstein
experiments/
  config.py              all sizes / seeds / paths
  gen_data.py            simulate train / test / misspecification datasets
  train_models.py        train NPE (CNN+MAF), NPE (summaries), CNN regressor
  eval_calibration.py    SBC / coverage / recovery / misspecification
  run_mcmc.py            gold-standard NUTS on a subset of test datasets
  eval_mcmc.py           NPE-vs-NUTS comparison (C2ST, Wasserstein, timing)
  make_figures.py        all publication figures + LaTeX tables
  gen_macros.py          inline numeric macros for the paper
  run_pipeline.sh        orchestrates every stage end-to-end
paper/                   LaTeX source, figures, compiled PDF
```

## Reproducing

```bash
pip install -r requirements.txt
export PYTHONPATH=$PWD
cd experiments
python gen_data.py          # ~2 min
python train_models.py      # ~25 min (4 CPU cores)
bash run_pipeline.sh        # calibration + MCMC + figures + compile
```

Every figure and number in the paper is regenerated by this pipeline; there are
no hand-entered results.
